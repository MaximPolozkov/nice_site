# Ниши недели — сайт и бот

Сайт с ботом, который раз в неделю сам ищет ниши для агентских сделок по всей России.

- **Публичная страница** `/` — топ ниш недели: комиссия с одной сделки, спрос по Яндекс Вордстату, рост, сезон, конкуренция. Плюс `/archive`.
- **Панель** `/admin` (по паролю) — запуск бота кнопкой, все оценённые ниши с разбором баллов, выбор, что показывать на сайте, отправка отчёта в VK, учёт заявок, сделок и комиссии.
- **Бот** работает в отдельном контейнере: по расписанию и по кнопке из панели.

Всё запускается одной командой через Docker. HTTPS-сертификат для домена выпускается автоматически (Caddy + Let's Encrypt).

```
Интернет → caddy (80/443, HTTPS) → web (сайт, Flask)
                                       ↕ общая база SQLite (том data)
                                   worker (бот, расписание)
```

## Деплой на kodverks.ru

Сайт заменяет прежний сайт студии на том же домене и берёт ключи из его `.env`.

### 1. Остановить старый сайт

```bash
cd /путь/к/kodeverks
docker compose -f docker-compose.yml -f docker-compose.prod.yml down
```

Тома с базой старого сайта при этом не удаляются. Его `.env` пригодится на шаге 3.

Ещё отключите то, что вело на старый сайт:

- **VK:** сообщество → Управление → Работа с API → Callback API — удалите сервер `https://kodverks.ru/api/webhooks/vk`, иначе VK будет слать события на несуществующий адрес.
- **Telegram:** `https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/deleteWebhook`, если вебхук был настроен.

### 2. Загрузить проект

С вашего компьютера:

```bash
scp niche_site.zip root@IP-сервера:/opt/
```

На сервере:

```bash
cd /opt && apt install -y unzip && unzip niche_site.zip && cd niche_site
```

### 3. Установить, взяв ключи старого сайта

Если у вас есть готовый `kodverks.env` (домен, VK_GROUP_ID, SECRET_KEY и пароль уже вписаны), положите его в папку проекта как `.env`:

```bash
cp /путь/к/kodverks.env .env
```

Затем:

```bash
sudo bash deploy/install.sh /путь/к/kodeverks/.env
```

Если `.env` уже лежит в папке, установщик заполнит из старого только пустые ключи, а всё, что вписано, оставит.

Установщик:
- скопирует старый `.env` и допишет настройки бота ниш;
- включит HTTPS-куки, сгенерирует `SECRET_KEY`, если его нет;
- пароль панели возьмёт из `FIRST_ADMIN_PASSWORD` старого сайта (или создаст новый и покажет);
- проверит, что порты 80/443 свободны, и что домен смотрит на сервер;
- соберёт и запустит контейнеры, включит ежедневную копию базы.

Какие ключи переходят без изменений:

| Старый `.env` | Для чего в боте ниш |
|---|---|
| `LLM_PROVIDER`, `LLM_API_KEY`, `LLM_MODEL`, `LLM_BASE_URL` | генерация и оценка ниш |
| `VK_GROUP_TOKEN`, `VK_NOTIFY_PEER_IDS` | отчёт о нишах вам в личку VK |
| `VK_GROUP_ID` | кнопка «Сообщество VK» на сайте |
| `SERPAPI_KEY` | поиск цен, если нейросеть без своего веб-поиска |
| `FIRST_ADMIN_PASSWORD` | пароль панели `/admin` |

Нейросеть необязательна. Если в `.env` `LLM_PROVIDER=none` или нет ключа, бот работает по встроенному каталогу из 70+ ниш (`bot/catalog.py`): спрос, рост и сезон — из Вордстата, чек — типичный диапазон из каталога, уточнённый по выдаче Яндекса через SerpAPI, если есть `SERPAPI_KEY`. Подключите нейросеть позже — бот начнёт сам придумывать ниши и точнее оценивать цены.

### 4. Вордстат и боевой режим

Ключа Вордстата в старом `.env` нет, поэтому сайт стартует в **демо-режиме**: бот работает на выдуманных данных, а на главной висит пометка «пример». API Вордстата теперь работает через Yandex Cloud. Создайте в консоли Yandex Cloud сервисный аккаунт, дайте ему на каталог роль `search-api.webSearch.user`, выпустите для него API-ключ и впишите:

```bash
nano .env          # WORDSTAT_API_KEY=..., WORDSTAT_FOLDER_ID=b1g..., DEMO_MODE=0
docker compose up -d
```

Затем в панели нажмите «Удалить демо-запуски» и «Найти ниши». Первый боевой запуск лучше сделать со снятой галочкой «Отправить отчёт в VK».

### Другой домен или чистый сервер

`sudo DOMAIN=example.ru bash deploy/install.sh` — без пути к старому `.env` установщик возьмёт `.env` из папки проекта (скопируйте `.env.example` в `.env` и заполните).

## Бесплатный режим

Бот работает без единого платного сервиса:

| Что | Бесплатно | Платно (точнее) |
|---|---|---|
| Ниши и экономика | каталог из 73 ниш (`bot/catalog.py`) | нейросеть: YandexGPT или Claude |
| Спрос и рост | VK API: число публичных постов за 30 дней и год назад (`VK_USER_TOKEN` или `VK_SERVICE_TOKEN`) | Вордстат в Yandex Cloud: поисковые запросы |
| Сезон | месяцы пика из каталога | динамика Вордстата за 2 года |
| Цены | каталог + SerpAPI для топ-10 (≈40 запросов в месяц при бесплатных 100) | — |

Важно: посты VK — это активность обсуждения (в неё попадают и покупатели, и продавцы), а не поисковый спрос. Для сравнения ниш между собой этого хватает, но абсолютные числа с Вордстатом не сравнимы. Когда подключите Вордстат (`WORDSTAT_API_KEY`), бот переключится на него сам.

## Ключи

| Что | Где взять | Переменные |
|---|---|---|
| Вордстат | Yandex Cloud: сервисный аккаунт с ролью `search-api.webSearch.user` на каталог → API-ключ; ID каталога из консоли. Около 20 ₽ за 1000 запросов, один прогон ≈ 150 запросов | `WORDSTAT_API_KEY`, `WORDSTAT_FOLDER_ID` |
| Нейросеть (необязательно) | Ключ Claude API на platform.claude.com/settings/keys (ключ привяжите к workspace) или YandexGPT (пример в `.env.example`). Без ключа работает каталог ниш | `LLM_API_KEY`, `LLM_PROVIDER`, `LLM_MODEL` |
| SerpAPI (необязательно) | serpapi.com — уточняет цены по выдаче Яндекса | `SERPAPI_KEY` |
| VK, отчёт в личку | Сообщество → Управление → Работа с API → ключ с правом «Сообщения». Ваш VK ID. Напишите сообществу любое сообщение | `VK_GROUP_TOKEN`, `VK_ADMIN_PEER_IDS` |
| VK, пост на стену | Ключ администратора через VK ID с правом `wall`. С ключом сообщества VK стену обычно не даёт | `VK_USER_TOKEN`, `VK_GROUP_ID`, `PUBLISH_MODE=wall` |

## Обслуживание

```bash
docker compose logs -f worker                       # что делает бот
docker compose restart                              # перезапуск
docker compose exec worker python cli.py backup     # копия базы в том data (/data/backups)
docker compose cp worker:/data/backups ./backups    # забрать копии на сервер в ./backups
```

Обновление после изменений кода: заменить файлы и выполнить `sudo bash deploy/update.sh` — он сделает копию базы и пересоберёт контейнеры. База лежит в томе `data` и при пересборке не теряется. Ежедневную копию базы в 4:00 включает установщик.

## Как бот оценивает ниши

| Фактор | Вес | Источник |
|---|---|---|
| Комиссия с одной сделки | 30% | чек × % (нейросеть) |
| Спрос в месяц | 25% | Вордстат |
| Рост год к году | 15% | Вордстат: последние 3 месяца против тех же месяцев год назад |
| Сезон | 15% | Вордстат: максимум, если пик через 1–3 месяца |
| Конкуренция | 15% | нейросеть |

В топ попадают только ниши со средней комиссией от `MIN_COMMISSION_RUB` (по умолчанию 15 000 ₽). Ниши, бывшие в топе последние 8 недель, не повторяются. Веса — в `bot/scoring.py`.

Авито бот не парсит: пользовательское соглашение площадки запрещает автоматический сбор объявлений.

## Структура

```
bot/            логика бота: Вордстат, нейросеть или каталог ниш (catalog.py), оценка, база, VK
web/            сайт: app.py, шаблоны, стили
worker.py       расписание и ручные запуски
cli.py          команды для консоли
deploy/         install.sh, update.sh
Dockerfile, docker-compose.yml, Caddyfile
```

## Локальный запуск без Docker

```bash
pip install -r requirements.txt
cp .env.example .env    # DEMO_MODE=1, COOKIE_SECURE=0, ADMIN_PASSWORD=...
python worker.py &
flask --app web.app run
```
